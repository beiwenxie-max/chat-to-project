# Chat to Project 智能体规则

当用户提出将当前普通聊天、头脑风暴或代码方案保存/迁移/移动到具体项目工作区时：
1. **主动激活**：优先触发 `chat-to-project` 技能，遵循其标准化作业流程 (SOP)。
2. **完整保留上下文**：务必梳理出结构化的 `PROJECT_CONTEXT.md`，包含技术决策、已确认实现及下一步待办，确保在目标项目开启新会话时不丢失思维链。
3. **安全迁移资产**：将当前会话在临时目录或脑图/草稿中创建的代码与方案落盘至目标项目。
4. **友好操作指引**：在操作完成后，提示用户在 Antigravity 侧边栏打开该项目工作区，实现无缝衔接。
